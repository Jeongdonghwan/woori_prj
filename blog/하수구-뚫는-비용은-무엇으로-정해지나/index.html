네 가지 조건이 값을 만듭니다

하수구 뚫는 비용은 막힌 위치, 막힌 원인, 필요한 장비, 작업 시간대로 정해집니다. 전화로 정확한 금액이 나오기 어려운 까닭도 여기에 있습니다. 바닥 배수구 바로 아래의 머리카락과 건물 밖 맨홀까지 이어진 기름 슬러지는 이름만 같은 '하수구 막힘'일 뿐 다른 일입니다.

위치: 입구에서 얼마나 깊은가

트랩을 분해해 손이 닿는 자리라면 작업이 짧습니다. 바닥 아래 깊은 구간, 여러 집이 쓰는 공용 구간, 외부 맨홀과 메인 배관까지 문제가 이어지면 세척 범위와 시간이 늘어납니다. 건물에 들어갈 호스 길이, 장비를 세울 자리, 차량 접근이 되는지도 영향을 줍니다.

원인: 무엇이 얼마나 굳었나

머리카락과 비누 찌꺼기는 스프링이나 간단한 장비로 끝나기도 합니다. 그런데 음식점 주방에서 돌처럼 굳은 기름덩어리, 공사 때 들어간 시멘트 찌꺼기와 모래, 주먹만 한 돌이 나오는 현장은 다릅니다. 불당동의 한 화장실은 돌이 걸려 있어 일반 뚫음보다 시간이 훨씬 오래 걸렸습니다.

장비: 어떤 조합이 필요한가

  • 배관 내시경: 원인과 위치를 확인할 때
  • 플렉스샤프트: 좁은 관 안쪽의 기름 스케일을 긁어낼 때
  • 고압세척기: 관 전체를 씻어야 할 때
  • 석션 장비: 오수나 찌꺼기를 빨아내야 할 때
  • 관통 장비: 물길 자체가 끊겼을 때

한 가지로 끝나는 현장도, 여러 장비를 같이 쓰는 현장도 있습니다. 비용 차이는 대개 이 조합과 범위에서 납니다.

시간대와 건물 조건

야간이나 영업시간을 피해야 하는 상가, 지하층, 보양을 넓게 해야 하는 매장은 작업 준비가 늘어납니다. 창고처럼 바닥 오염에 민감한 곳은 작업 전 바닥과 집기를 덮는 데도 시간이 듭니다.

값이 커지기 전에 할 수 있는 일

약품을 여러 번 넣고 나서 부르는 경우도 많은데, 약품이 얼마나 남아 있는지 모르면 작업 전에 물을 빼고 조심해야 해서 일이 더뎌집니다. 무엇을 언제 넣었는지 적어 두세요.
